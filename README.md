<h3>🚀 Projetos em destaque</h3>

<h4>🏫 <a href="https://github.com/juniorferreira22/sistema-chamados-escolas">Sistema de Chamados - Escolas Municipais</a></h4>
<p>
  Plataforma web para gestão de chamados técnicos de escolas municipais, com dois perfis de acesso:
  escolas, que abrem e acompanham chamados, e técnicos, que gerenciam atendimentos, prazos e status.
</p>
<ul>
  <li><strong>O que foi construído:</strong> autenticação por perfil, dashboards distintos para escolas e técnicos, fluxo completo de abertura, atribuição, acompanhamento e finalização de chamados, além de histórico de alterações e feedback.</li>
  <li><strong>Responsabilidades:</strong> modelagem do banco de dados com Prisma, desenvolvimento das APIs e regras de negócio no Next.js, autenticação segura com JWT e cookies HTTP-only, e construção da interface responsiva com TailwindCSS.</li>
  <li><strong>Decisões técnicas:</strong> uso de Next.js (App Router) para unificar front-end e back-end em um só projeto, PostgreSQL com Prisma ORM pela robustez em dados relacionais, e cookies HTTP-only para reduzir a superfície de ataque a XSS.</li>
  <li><strong>Stack:</strong> Next.js, PostgreSQL, Prisma, TailwindCSS, JWT.</li>
</ul>

<h4>🎮 <a href="https://github.com/juniorferreira22/reduto">Reduto</a></h4>
<p>
  Aplicação web criada para uma comunidade de jogadores de CS2, permitindo organizar partidas competitivas
  amistosas ("mix") e campeonatos locais dentro de um servidor Discord.
</p>
<ul>
  <li><strong>O que foi construído:</strong> área administrativa protegida, autenticação server-side e renderização híbrida usando Server e Client Components.</li>
  <li><strong>Responsabilidades:</strong> implementação do fluxo de login e emissão de JWT no servidor, proteção de rotas administrativas e definição da estrutura do projeto (app, components, lib, api).</li>
  <li><strong>Decisões técnicas:</strong> autenticação validada inteiramente no servidor, com token armazenado em cookie HTTPOnly (sem exposição em localStorage), reduzindo riscos de XSS; migração futura planejada para Prisma e banco relacional.</li>
  <li><strong>Stack:</strong> Next.js, React, TailwindCSS, JWT.</li>
  <li>🔗 Deploy: <a href="https://reduto-seven.vercel.app">reduto-seven.vercel.app</a></li>
</ul>
